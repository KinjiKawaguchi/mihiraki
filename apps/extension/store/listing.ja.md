# ストア掲載文（日本語）

## 説明

GitHubのプルリクエストで、Markdownの変更を「読むときの形」のまま確認できます。変更前を左、変更後を右にレンダリングして並べ、その場でレビューコメントを付けられます。

GitHub標準のrich diffは、Markdownの変更前後を1つの画面に重ねて表示し、レビューコメントも付けられません。Mihirakiは、プルリクエストの「Files changed」タブで変更されたMarkdownファイルをrich diffに切り替えると、その表示に置き換わります。GitHubのSplit / Unifiedの設定に従います。

• Split: 変更前後をそれぞれ描画し、見出し・段落・リスト・表などのブロック単位で左右に揃えます
• Unified: 1列で、変更箇所をその場に示します
• 変更されたブロックの中は、語単位（日本語と中国語は文字単位）で差分を強調します
• ブロックにマウスを重ねて「+」を押すとコメント、ドラッグすると範囲を選べます（GitHub本来の差分表示と同じ操作です）
• コメントはGitHubの通常のレビューコメントです。すぐに投稿することも、保留中のレビューに加えることもできます
• 既存のレビュースレッドは対象の本文の横に表示され、その場で返信、引用、解決のほか、自分のコメントの編集・削除やリアクションもできます
• GitHub本来のrich diffで見たいファイルは、ワンクリックでそのファイルだけ元に戻せます。戻すのもワンクリックです
• mermaidの図はGitHubと同じ見た目で描き、変更前後を左右に並べます
• 外部サイトの画像は、GitHubと同じく画像プロキシを通して読み込みます。プロキシを通せない画像は、クリックするまで読み込みません
• 表示言語は日本語と英語です。はじめはブラウザの言語に合わせ、ツールバーのアイコンから切り替えられます
• ブラウザでサインイン済みのGitHubのセッションを使います。トークンの設定は不要で、必要な権限は github.com へのアクセスと、表示言語の保存だけです
• データを収集しません。通信先はGitHub（github.com と、GitHub自身の図の描画サービス）だけです

## プライバシーへの取り組み

**単一用途**: GitHubのプルリクエストで変更されたMarkdownファイルを、変更前後を左右に並べてレンダリングし、その場でレビューとコメントができるようにします。

**ホスト権限（https://github.com/* でのコンテンツスクリプト）**: github.com のプルリクエストのページに、左右分割の表示を加えるために使います。変更されたファイルとレビューのスレッドの読み取り、および利用者が行うコメントの投稿・返信・編集・削除、リアクション、スレッドの解決を、利用者のサインイン済みセッションで github.com に対して行います。mermaidの図は、GitHub自身のページと同じく、GitHubの描画サービス（viewscreen.githubusercontent.com）のフレームで描きます。ほかのサイトでは動作しません。

**storage 権限**: ツールバーのポップアップで選んだ表示言語を保存するために使います。保存するのはこの設定だけです。

**リモートコード**: 使用しません。すべてのコードは拡張機能に同梱しています。図を描くフレームはGitHub自身のページで、GitHubが埋め込むのと同じく、拡張機能からは隔離されています。

**データの使用**: 一覧のいずれのデータも収集しません。開発者や第三者にデータを送信しません。コメントとその編集・削除、リアクションは利用者が操作したときに github.com へ、mermaidの図のコードは描画のためにGitHubの描画サービスへ送るだけです。
