# デプロイ手順書

APIサービスを本番環境へリリースする手順をまとめる。

## デプロイ前の確認

- mainブランチのCIが通っていること
- 1時間前までに #deployments チャンネルでデプロイを告知すること
- 対応中の障害がないこと
- データベースのマイグレーションに後方互換性があること

## 段階的なリリース

リリースは3段階で行う。まずサーバーの5%、次に25%に配信し、各段階で15分間エラー率を監視する。

エラー率が0.5%を超えたら、リリースを止めてロールバックする。

## ロールバック

直前のバージョン番号を指定して `deploy rollback` を実行する。ロールバックには約5分かかる。

| 環境 | 承認者 | 実施できる時間帯 |
| --- | --- | --- |
| ステージング | 誰でも | いつでも |
| 本番 | チームリーダー | 月〜木 10:00〜15:00 |
